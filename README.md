# Smartphone_Usage_and_Productivity
This project is an end-to-end data analysis project focused on understanding how to distinguish productive smartphone use from distracting use. The objective is to uncover actionable insights that can help everyone manage their smartphone usage while improving their productivity through data-driven decision-making, Using Python, SQL and Power BI.
# Tools Used
Python Jupyter Pandas SQL Power BI

# Work Flow
Imported the dataset into Jupyter.
Cleaned and prepared the data using Pandas.
Loaded the cleaned data into PostgreSQL.
Performed SQL queries to answer business questions.
Created DAX measures and KPIs in Power BI.
Designed an interactive dashboard.
Generated insights and recommendations.
